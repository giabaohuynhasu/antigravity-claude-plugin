## 📦 How to Install in Claude Cowork

1. Open **Claude Desktop / Claude Cowork**.
2. Go to **Settings ⚙️ -> Plugins / Marketplace** (or click **Add Marketplace**).
3. In the repository URL input, enter:
   ```text
   https://github.com/giabaohuynhasu/antigravity-claude-plugin
   ```
   *(or `giabaohuynhasu/antigravity-claude-plugin`)*
4. Click **Add / Install**. All 4 skills (`/antigravity`, `/alrp-queueing`, `/cna-census`, `/mcp-builder`) will immediately appear in your Claude Cowork slash menu!
